| Kachel | Modul | Symbol | Farbe (dunkel) | Farbe (hell) |
|---|---|---|---|---|
| oben links | Music Architect V7 | Note | `#00e5ff` | `#00b8cc` |
| oben rechts | DAW Light Version | Fader | `#9945ff` | `#7c3aed` |
| unten links | Music Catalogue Manager v.2 | Liste | `#ffd700` | `#e0b000` |
| unten rechts | Sample Architect | Wellenform | `#ff2d9e` | `#e0157f` |

Symbole: `#060a18` · Schriftzug: `#c8e6ff` (dunkel) / `#0a0e22` (hell) · Akzent „-A.I“: `#00e5ff` / `#0090a8`

## Hinweis zur Schrift

Der Schriftzug nutzt die Schrift **Sora** (Google Fonts, Open Font License) als `<text>`.
Ist Sora nicht installiert, wird eine Ersatzschrift angezeigt. Für Druck oder Präsentation
Sora installieren oder den Text in einem Grafikprogramm in Pfade umwandeln.
